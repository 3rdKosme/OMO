# Разбор кода лабораторной работы № 4

**Построчное объяснение `lab4.py`**

Программа обучает линейный SVM на выборке варианта 7: находит прямую, которая разделяет
классы +1 и −1 с максимально широкой полосой, считает ошибки и рисует результат.

## Строки 1–3: импорты

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.svm import SVC
```

- `numpy` — массивы и векторные операции.
- `matplotlib.pyplot` — график.
- `SVC` (Support Vector Classifier) — классификатор методом опорных векторов из
  scikit-learn. Само обучение (решение задачи квадратичного программирования) делает он,
  вручную градиент считать не нужно.

## Строки 5–23: данные варианта 7

```python
data_x = [(3.0, 1.3), (3.4, 1.6), ...]
data_y = [1, 1, -1, -1, ...]
```

Та же выборка, что в ЛР3: 100 объектов с двумя признаками `(x1, x2)` и 100 ответов ±1.

---

## Строки 25–26: массивы

```python
x_train = np.array(data_x)
y_train = np.array(data_y)
```

- `x_train` — матрица 100×2, строка = объект, столбцы = x₁ и x₂.
- `y_train` — вектор из 100 классов.

Отличие от ЛР3: фиктивная единица **не добавляется**. `SVC` сам подбирает свободный член w₀
и хранит его отдельно в `intercept_`. Если добавить столбец единиц, w₀ попал бы в `coef_`
и стал бы штрафоваться регуляризатором ‖w‖², что неправильно.

## Строки 28–35: сравнение разных C

```python
for c in [0.1, 1, 10, 100, 1000]:
    model = SVC(kernel="linear", C=c).fit(x_train, y_train)
    w = model.coef_[0]
    errors = np.sum(model.predict(x_train) != y_train)
    print(...)
```

Дополнительная часть: показывает, как параметр C влияет на решение.

- `SVC(kernel="linear", C=c)` — линейный SVM с параметром регуляризации C.
  `.fit(...)` обучает и возвращает саму модель, поэтому можно писать в одну строку.
- `model.coef_[0]` — вектор (w₁, w₂). `coef_` имеет форму 1×2 (одна строка на
  разделяющую прямую), `[0]` берёт эту строку.
- `model.predict(x_train) != y_train` — массив True/False, где True там, где модель ошиблась.
  `np.sum` считает True, это число ошибок.
- `len(model.support_)` — число опорных векторов.
- `2 / np.linalg.norm(w)` — ширина полосы 2/‖w‖ (`norm` — длина вектора √(w₁² + w₂²)).

Вывод:

```
    C  |   w1      w2      w0   | ошибок | опорных | ширина полосы
  0.1 | -0.715   1.607   0.966 |      0 |      37 | 1.1371
    1 | -0.984   2.014   1.346 |      0 |       8 | 0.8923
   10 | -0.834   3.333  -0.082 |      0 |       3 | 0.5822
  100 | -0.834   3.333  -0.082 |      0 |       3 | 0.5822
 1000 | -0.834   3.333  -0.082 |      0 |       3 | 0.5822
```

Чем меньше C, тем дешевле нарушения, тем шире полоса и тем больше объектов в неё попадает
(все они становятся опорными). С C = 10 нарушений уже нет, и решение дальше не меняется.

## Строки 37–39: основная модель

```python
model = SVC(kernel="linear", C=1000)
model.fit(x_train, y_train)
```

- Выборка линейно разделима, поэтому берём большое C: нарушения фактически запрещены,
  получается SVM с жёстким зазором — прямая с максимальной полосой без объектов внутри.
- `fit` решает двойственную задачу: находит λᵢ для каждого объекта, по ним веса
  w = Σλᵢyᵢxᵢ и сдвиг w₀.

---

## Строки 41–44: веса и ошибки

```python
w = model.coef_[0]
w0 = model.intercept_[0]
y_pred = model.predict(x_train)
errors = np.sum(y_pred != y_train)
```

- `w` = (w₁, w₂) = (−0.8336, 3.3328).
- `w0` = −0.0822. `intercept_` — массив из одного числа, `[0]` достаёт само число.
- `predict` для каждого объекта считает sign(w₁x₁ + w₂x₂ + w₀) и возвращает ±1.
- `errors` — число неверных классификаций.

---

## Строки 46–54: печать результатов

```python
print("w1 = %.4f, w2 = %.4f, w0 = %.4f" % (w[0], w[1], w0))
print("Разделяющая линия: %.4f*x1 %+.4f*x2 %+.4f = 0" % (w[0], w[1], w0))
print("Ширина разделяющей полосы 2/|w| = %.4f" % (2 / np.linalg.norm(w)))
print("Опорные векторы (по классам %s):" % model.n_support_)
for i in model.support_:
    print("   x = %s, y = %+d, M = %.4f" % (x_train[i], y_train[i], y_train[i] * (x_train[i] @ w + w0)))
print("Число неверных классификаций = %d из %d" % (errors, len(y_train)))
print("Доля неверных классификаций = %.2f" % (errors / len(y_train)))
```

- `%+.4f` печатает число всегда со знаком, поэтому уравнение выглядит как
  `-0.8336*x1 +3.3328*x2 -0.0822 = 0`, а не `+ -0.0822`.
- `model.n_support_` — число опорных векторов по классам: `[2 1]` (2 из класса −1, 1 из +1;
  классы идут по возрастанию).
- `model.support_` — индексы опорных векторов в выборке: 52, 54, 47. Цикл печатает каждый
  объект, его класс и отступ M = y·(⟨w, x⟩ + w₀). У всех трёх M ≈ 1: они лежат ровно на
  границах полосы, как и должно быть по теории.
- Доля ошибок = число ошибок / 100.

Вывод:

```
w1 = -0.8336, w2 = 3.3328, w0 = -0.0822
Разделяющая линия: -0.8336*x1 +3.3328*x2 -0.0822 = 0
Ширина разделяющей полосы 2/|w| = 0.5822
Опорные векторы (по классам [2 1]):
   x = [3.5 0.6], y = -1, M = 1.0002
   x = [2.3 0.3], y = -1, M = 0.9997
   x = [2.7 1. ], y = +1, M = 0.9998
Число неверных классификаций = 0 из 100
Доля неверных классификаций = 0.00
```

Отступы не ровно 1, а 0.9997–1.0002: `SVC` решает задачу численно с точностью
`tol = 0.001`.

### Проверка вручную

Опорный вектор (2.7; 1.0), класс +1:

⟨w, x⟩ + w₀ = −0.8336·2.7 + 3.3328·1.0 − 0.0822 = −2.2507 + 3.3328 − 0.0822 = 0.9999 ≈ 1.

Веса через двойственные коэффициенты (`model.dual_coef_` = λᵢyᵢ = −2.662, −3.240, 5.902):

w₁ = −2.662·3.5 − 3.240·2.3 + 5.902·2.7 = −9.317 − 7.452 + 15.935 = −0.834
w₂ = −2.662·0.6 − 3.240·0.3 + 5.902·1.0 = −1.597 − 0.972 + 5.902 = 3.333

Совпадает с `coef_`: прямую действительно задают только три опорных объекта.
Сумма λᵢyᵢ = −2.662 − 3.240 + 5.902 = 0, как требует ограничение двойственной задачи.

## Строки 56–60: линии для графика

```python
line_x = np.linspace(1.8, 4.6, 2)
line_y = -(w0 + w[0] * line_x) / w[1]
margin_up = -(w0 - 1 + w[0] * line_x) / w[1]
margin_dn = -(w0 + 1 + w[0] * line_x) / w[1]
```

- `line_x` — две точки по x₁ (1.8 и 4.6), для прямой этого достаточно.
- `line_y` — разделяющая прямая w₁x₁ + w₂x₂ + w₀ = 0, решённая относительно x₂:
  x₂ = −(w₀ + w₁x₁)/w₂ ≈ 0.250·x₁ + 0.025.
- `margin_up` — граница полосы со стороны класса +1: w₁x₁ + w₂x₂ + w₀ = +1, то есть
  x₂ = −(w₀ − 1 + w₁x₁)/w₂.
- `margin_dn` — граница со стороны класса −1: w₁x₁ + w₂x₂ + w₀ = −1.

Все три прямые параллельны (один наклон), вертикальное расстояние между границами
2/w₂ ≈ 0.6.

## Строки 62–77: график

```python
pos = y_train == 1
neg = y_train == -1
plt.scatter(x_train[pos, 0], x_train[pos, 1], c="green", marker="o", label="класс +1")
```

- `pos`, `neg` — булевы маски классов.
- `x_train[pos, 0]` — x₁ объектов класса +1, `x_train[pos, 1]` — их x₂. Столбцы теперь 0 и 1
  (в ЛР3 были 1 и 2, потому что в столбце 0 стояли единицы).
- Класс +1 — зелёные кружки, класс −1 — синие крестики: разные маркеры и цвета, как
  требует задание.

```python
sv = x_train[model.support_]
plt.scatter(sv[:, 0], sv[:, 1], s=150, facecolors="none", edgecolors="black", label="опорные векторы")
```

- `sv` — строки выборки с индексами опорных векторов.
- Рисуются большие (`s=150`) пустые (`facecolors="none"`) чёрные кружки поверх точек —
  так опорные векторы обведены.

```python
plt.plot(line_x, line_y, c="red", label="разделяющая линия")
```

- Сплошная красная — разделяющая прямая, тонкие красные пунктиры (`"r--"`) — границы полосы.

Остальное:

  не закрывает точки.

На графике видно: все зелёные точки выше верхней пунктирной линии, все синие — ниже
нижней, внутри полосы точек нет, а три обведённых объекта лежат ровно на её границах.
