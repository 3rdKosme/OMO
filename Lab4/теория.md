# Теория к лабораторной работе № 4

**Задача классификации: метод опорных векторов (SVM, Support Vector Machine)**

Эта лаба продолжает ЛР3. Там линейный классификатор обучали градиентным спуском по
сигмоидной функции потерь, здесь — методом опорных векторов с помощью готовой
библиотеки scikit-learn.

---

## 1. Постановка задачи

Обучающая выборка Xˡ = {(x₁, y₁), …, (xℓ, yℓ)}, где xᵢ = (x₁ᵢ, x₂ᵢ) — признаки, yᵢ ∈ {−1, +1} — класс.
В варианте 7 ℓ = 100, по 50 объектов каждого класса.

Модель — линейный классификатор:

**a(x) = sign(⟨w, x⟩ + w₀) = sign(w₁x₁ + w₂x₂ + w₀)**

- w = (w₁, w₂) — вектор нормали к разделяющей прямой;
- w₀ — свободный член (сдвиг). В ЛР3 он был ω₀ при фиктивном признаке x₀ = 1, в SVM его
  принято писать отдельно, потому что он не входит в регуляризацию ‖w‖².

Разделяющая прямая: w₁x₁ + w₂x₂ + w₀ = 0.

**Отступ** объекта: Mᵢ = yᵢ·(⟨w, xᵢ⟩ + w₀). M > 0 — объект классифицирован верно, M < 0 — ошибка.

---

## 2. Какую прямую выбрать

Если выборка линейно разделима, разделяющих прямых бесконечно много: прямую можно
немного сдвинуть или повернуть, и она всё равно будет без ошибок. Градиентный спуск в ЛР3
находит одну из них — какую именно, зависит от начальных весов, шага и числа итераций.

Интуиция SVM: лучше всего та прямая, которая проходит **как можно дальше от ближайших
объектов обоих классов**. Тогда небольшой шум в новых объектах не перекинет их на чужую
сторону. Такая прямая называется **оптимальной разделяющей гиперплоскостью**.

---

## 3. Ширина разделяющей полосы

### Расстояние от точки до прямой

Расстояние от точки x до прямой ⟨w, x⟩ + w₀ = 0:

**ρ(x) = |⟨w, x⟩ + w₀| / ‖w‖**

### Нормировка

Веса (w, w₀) определены с точностью до множителя: прямые 2x₁ + x₂ = 0 и 4x₁ + 2x₂ = 0 —
одна и та же прямая. Поэтому их можно нормировать как угодно. В SVM выбирают нормировку,
при которой у ближайших к прямой объектов отступ равен 1:

**minᵢ Mᵢ = 1**, т.е. yᵢ·(⟨w, xᵢ⟩ + w₀) ≥ 1 для всех i.

### Полоса

Тогда между прямыми ⟨w, x⟩ + w₀ = +1 и ⟨w, x⟩ + w₀ = −1 нет ни одного объекта.
Это **разделяющая полоса**, а разделяющая прямая проходит ровно посередине.

Расстояние от разделяющей прямой до каждой из границ равно 1/‖w‖, поэтому

**ширина полосы = 2 / ‖w‖**.

---

## 4. Жёсткий зазор (hard margin)

Максимизировать 2/‖w‖ — то же самое, что минимизировать ‖w‖² (квадрат и ½ берут для
удобства дифференцирования):

**½‖w‖² → min по w, w₀**

**при ограничениях yᵢ·(⟨w, xᵢ⟩ + w₀) ≥ 1, i = 1, …, ℓ.**

Это задача **квадратичного программирования**: квадратичная выпуклая функция и линейные
ограничения. У неё единственное решение, и его можно найти точно, без подбора шага и
начального приближения.

Недостаток: если выборка линейно неразделима, ни одна прямая не удовлетворит всем
ограничениям, и задача не имеет решения. Кроме того, один выброс сильно сдвигает прямую.

---

## 5. Мягкий зазор (soft margin)

Ограничения ослабляют: каждому объекту разрешают зайти внутрь полосы или даже на чужую
сторону, но за это штрафуют. Вводят переменные **ξᵢ ≥ 0** (slack variables):

**½‖w‖² + C·Σᵢ ξᵢ → min по w, w₀, ξ**

**при ограничениях yᵢ·(⟨w, xᵢ⟩ + w₀) ≥ 1 − ξᵢ, ξᵢ ≥ 0.**

Смысл ξᵢ:

| ξᵢ | Где объект |
|---|---|
| 0 | за пределами полосы на своей стороне (или на её границе) |
| 0 < ξᵢ < 1 | внутри полосы, но ещё на своей стороне — классифицирован верно |
| ξᵢ = 1 | на самой разделяющей прямой |
| ξᵢ > 1 | на чужой стороне — ошибка |

Значит, Σξᵢ — верхняя оценка числа ошибок.

### Параметр C

C — коэффициент **регуляризации**, задаёт компромисс:

- **большое C** — нарушения штрафуются сильно, решение стремится к жёсткому зазору:
  полоса узкая, ошибок мало, но модель чувствительна к выбросам (риск переобучения);
- **малое C** — нарушения дешёвые, важнее широкая полоса: внутрь неё попадает много
  объектов, возможны ошибки на обучающей выборке, зато модель грубее и устойчивее.

В scikit-learn по умолчанию C = 1.

---

## 6. Связь с функциями потерь из ЛР3

При оптимальных ξᵢ имеем ξᵢ = max(0, 1 − Mᵢ) = (1 − Mᵢ)₊. Подставив это, получаем
безусловную задачу:

**Σᵢ (1 − Mᵢ)₊ + (1/2C)·‖w‖² → min по w, w₀**

- (1 − M)₊ — **кусочно-линейная функция потерь (hinge loss)**. Как и сигмоидная в ЛР3,
  она лежит не ниже пороговой [M < 0], т.е. является её верхней оценкой.
- Отличие от других функций потерь: она равна нулю уже при M ≥ 1, а не только в пределе
  M → ∞. Объекты, отодвинутые от прямой дальше, чем на «единицу», не дают вклада вообще.
- ‖w‖² — **регуляризатор**, штрафующий большие веса. Именно он заставляет искать самую
  широкую полосу.

То есть SVM — это та же минимизация аппроксимированного эмпирического риска, что и в ЛР3,
только с hinge loss и с регуляризацией.

| | ЛР3 | ЛР4 (SVM) |
|---|---|---|
| Функция потерь | сигмоидная 2/(1 + e^M) | кусочно-линейная (1 − M)₊ |
| Регуляризация | нет | ‖w‖²/2C |
| Выпуклость | нет | да |
| Решение | зависит от старта и шага | единственное |
| Метод | градиентный спуск | квадратичное программирование |

---

## 7. Двойственная задача и опорные векторы

Через функцию Лагранжа с множителями λᵢ ≥ 0 задачу сводят к **двойственной**:

**−Σᵢ λᵢ + ½·Σᵢ Σⱼ λᵢλⱼ yᵢyⱼ ⟨xᵢ, xⱼ⟩ → min по λ**

**при 0 ≤ λᵢ ≤ C, Σᵢ λᵢyᵢ = 0.**

По найденным λ веса восстанавливаются как

**w = Σᵢ λᵢ·yᵢ·xᵢ**, а w₀ — из условия M = 1 для любого объекта на границе полосы.

По условиям Каруша–Куна–Таккера объекты делятся на три типа:

| λᵢ | Mᵢ | Тип объекта |
|---|---|---|
| 0 | > 1 | **периферийный** — далеко от прямой, на решение не влияет |
| 0 < λᵢ < C | = 1 | **опорный граничный** — лежит ровно на границе полосы |
| C | < 1 | **опорный нарушитель** — внутри полосы или на чужой стороне |

**Опорные векторы** — объекты с λᵢ > 0. Только они входят в сумму w = Σλᵢyᵢxᵢ, поэтому
только они определяют прямую. Отсюда и название метода. Обычно опорных векторов мало,
и это делает решение компактным.

### Ядра

В двойственную задачу признаки входят только через скалярные произведения ⟨xᵢ, xⱼ⟩.
Если заменить их на функцию K(xᵢ, xⱼ) (**ядро**), получится нелинейный SVM, например
с полиномиальным (`kernel="poly"`) или гауссовым (`kernel="rbf"`) ядром. В этой работе
нужен линейный вариант: `kernel="linear"`, K(x, x′) = ⟨x, x′⟩.

---

## 8. SVM в scikit-learn

```python
from sklearn.svm import SVC

model = SVC(kernel="linear", C=1.0)
model.fit(X, y)        # X — матрица ℓ×2, y — вектор классов
model.predict(X)       # предсказанные классы
```

Атрибуты обученной модели:

| Атрибут | Что хранит |
|---|---|
| `coef_` | вектор w (только для линейного ядра), форма 1×2 |
| `intercept_` | свободный член w₀ |
| `support_` | индексы опорных векторов в обучающей выборке |
| `support_vectors_` | сами опорные векторы |
| `n_support_` | число опорных векторов в каждом классе |
| `dual_coef_` | произведения λᵢ·yᵢ для опорных векторов |
| `decision_function(X)` | значения ⟨w, x⟩ + w₀ |

Есть также `LinearSVC` — он быстрее на больших выборках, но не хранит опорные векторы,
поэтому здесь используется `SVC`.

## 9. Оценка качества

**Число неверных классификаций** (эмпирический риск):

Q = Σᵢ [a(xᵢ) ≠ yᵢ]

**Доля неверных классификаций** (частота ошибок):

ν = Q / ℓ

Обе величины в программе считаются сравнением `model.predict(x_train)` с `y_train`.
