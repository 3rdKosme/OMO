# Разбор кода лабораторной работы № 3

**Построчное объяснение `lab3.py`**

Программа учит прямую, которая отделяет точки класса +1 от точек класса −1, и находит её
веса градиентным спуском.

## Строки 5–22: данные варианта 7

```python
data_x = [(3.0, 1.3), (3.4, 1.6), ...]
data_y = [1, 1, -1, -1, ...]
```

- `data_x` — 100 объектов, у каждого два признака `(x1, x2)`.
- `data_y` — 100 ответов: `+1` или `-1`, это класс объекта.
- Позиции совпадают: `data_x[0] = (3.0, 1.3)` имеет класс `data_y[0] = 1`.

## Строки 24–25: превращаем списки в матрицы

```python
x_train = np.array([[1, x1, x2] for x1, x2 in data_x])
y_train = np.array(data_y)
```

- Генератор проходит по всем парам и из `(x1, x2)` делает `[1, x1, x2]`.
- Единица спереди — фиктивный признак x₀ = 1. С ней выражение ω₀ + ω₁x₁ + ω₂x₂
  записывается как одно скалярное произведение ⟨ω, x⟩, и ω₀ не нужно обрабатывать отдельно.
- `x_train` — матрица 100×3 (строка = объект), `y_train` — вектор из 100 чисел.

## Строки 29–34: функция потерь и её производная

```python
def loss(m):
    return 2 / (1 + np.exp(m))

def dloss(m):
    return -2 * np.exp(m) / (1 + np.exp(m)) ** 2
```

- `loss` — сигмоидная функция потерь S(M) = 2 / (1 + e^M). Она получает отступ M и
  возвращает штраф:
  - M сильно положительный (объект уверенно на своей стороне) → штраф около 0;
  - M = 0 (объект на самой прямой) → штраф 1;
  - M сильно отрицательный (грубая ошибка) → штраф около 2.
- `dloss` — её производная S′(M) = −2e^M / (1 + e^M)². Она всегда отрицательна и по модулю
  максимальна при M = 0 (там −0.5).
- Обе функции принимают сразу весь массив отступов: `np.exp` применяется к каждому элементу.

Зачем это нужно: настоящая цель — число ошибок Σ[Mᵢ < 0]. Это ступенька, её производная
равна нулю почти везде, и градиентный спуск по ней не работает. Поэтому вместо неё
минимизируется гладкая функция, которая лежит не ниже ступеньки.

## Строки 37–39: настройки обучения

```python
w = np.array([0.0, 0.0, 1.0])
lr = np.array([0.5, 0.05, 0.05])
n_iter = 3000
```

- `w` — начальные веса (ω₀, ω₁, ω₂) = (0, 0, 1). Им соответствует прямая x₂ = 0, она лежит
  ниже всех точек, поэтому все объекты считаются классом +1 и ошибок 50 из 100.
- `lr` — шаг обучения, свой для каждого веса: 0.5 для ω₀ и по 0.05 для ω₁, ω₂. Шаг для ω₀
  больше, потому что в его градиенте стоит единица, а в градиентах ω₁, ω₂ — значения
  признаков (x₁ ≈ 2–4.4). Без этого сдвиг прямой подстраивался бы намного медленнее наклона.
- `n_iter` — число шагов спуска.

---

## Строки 41–46: цикл обучения

```python
for i in range(n_iter):
    m = y_train * (x_train @ w)
    grad = (dloss(m) * y_train) @ x_train / len(y_train)
    w = w - lr * grad
    if i % 500 == 0:
        print(...)
```

### Строка 42 — отступы

- `x_train @ w` — матрица 100×3 умножается на вектор из 3 чисел. Получается 100 чисел:
  для каждого объекта ω₀ + ω₁x₁ + ω₂x₂.
- Умножение на `y_train` идёт поэлементно и даёт отступ Mᵢ = yᵢ·⟨ω, xᵢ⟩.
- Если знак ⟨ω, xᵢ⟩ совпал с классом, то M > 0 (верно), иначе M < 0 (ошибка).

### Строка 43 — градиент

Это формула ∇Q̃ = (1/ℓ)·Σᵢ S′(Mᵢ)·yᵢ·xᵢ:

- `dloss(m) * y_train` — 100 коэффициентов cᵢ = S′(Mᵢ)·yᵢ, по одному на объект.
- `... @ x_train` — вектор из 100 чисел умножается на матрицу 100×3. Получается 3 числа:
  Σ cᵢ·1, Σ cᵢ·x₁ᵢ, Σ cᵢ·x₂ᵢ, то есть производные по ω₀, ω₁, ω₂.
- `/ len(y_train)` — деление на 100, чтобы получилось среднее.

### Строка 44 — шаг

ω ← ω − η·∇Q̃. Градиент показывает, куда функция растёт, поэтому идём в обратную сторону.
`lr * grad` умножается поэлементно: у каждого веса свой шаг.

### Строки 45–46 — печать

Каждые 500 итераций выводится Q̃ (`loss(m).mean()`, средний штраф) и веса.

Тонкость: `m` посчитан до обновления, а `w` печатается уже после. Поэтому в строке
«итерация 0» Q = 0.7727 относится к стартовым весам (0, 0, 1), а напечатанные веса — уже
после первого шага.

### Пример одного шага на двух объектах

Веса стартовые: ω = (0, 0, 1).

| | Объект 0 | Объект 2 |
|---|---|---|
| x, y | (1, 3.0, 1.3), y = +1 | (1, 3.4, 0.4), y = −1 |
| ⟨ω, x⟩ | 1.3 | 0.4 |
| Отступ M | 1.3 (верно) | −0.4 (ошибка) |
| S′(M) | −0.337 | −0.481 |
| Вклад в градиент S′·y·x | (−0.337, −1.010, −0.438) | (+0.481, +1.634, +0.192) |

- Объект 0: после вычитания градиента веса сдвигаются в сторону +x, его отступ растёт
  ещё больше.
- Объект 2: веса сдвигаются в сторону −x, значение ⟨ω, x⟩ уменьшается и уходит к
  отрицательному, как и нужно для класса −1.
- Ошибочный объект рядом с прямой тянет сильнее (0.481 против 0.337), потому что |S′|
  максимален около M = 0.

Так складываются вклады всех 100 объектов, и прямая постепенно встаёт между классами.

## Строки 48–53: итог

```python
m = y_train * (x_train @ w)
errors = np.sum(m < 0)
```

- Отступы пересчитываются с финальными весами.
- `m < 0` даёт массив из True/False, `np.sum` считает True. Это эмпирический риск,
  то есть число ошибок.
- Дальше печатаются веса, значение Q̃ и число ошибок.

Результат: ω = (2.4311, −2.6584, 7.2625), Q̃ = 0.0288, ошибок 0 из 100.

## Строки 56–57: разделяющая линия

```python
line_x = np.linspace(1.8, 4.6, 2)
line_y = -(w[0] + w[1] * line_x) / w[2]
```

- `linspace(1.8, 4.6, 2)` даёт две точки по x₁: 1.8 и 4.6. Для прямой двух точек достаточно.
- Вторая строка — уравнение ω₀ + ω₁x₁ + ω₂x₂ = 0, решённое относительно x₂:
  x₂ = −(ω₀ + ω₁x₁)/ω₂.
- С найденными весами получается x₂ ≈ 0.366·x₁ − 0.335: в точке 1.8 это 0.32, в точке 4.6
  это 1.35. Именно так идёт красная линия на `result.png`.

## Что видно в результатах

- **Главный признак — x₂.** У класса +1 x₂ ∈ [1.0; 1.8], у класса −1 x₂ ∈ [0.1; 0.6],
  поэтому ω₂ самый большой по модулю.
- **Q̃ падает с 0.77 до 0.029.** Ошибок при этом уже 0. Каждая ошибка даёт штраф не меньше 1,
  а сумма всех штрафов равна 100·0.029 ≈ 2.9, так что по одному Q̃ отсутствие ошибок здесь
  не доказывается — оно проверяется строкой 49.
- **С 1000-й по 3000-ю итерацию прямая почти не двигается, а веса растут примерно
  в 1.4 раза.** Выборка разделима, поэтому Q̃ можно уменьшать, просто умножая ω на число
  больше 1: все отступы растут, штрафы стремятся к 0. Конечного минимума нет, и обучение
  останавливают по числу итераций.
