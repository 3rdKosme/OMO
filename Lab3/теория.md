# Теория к лабораторной работе № 3

**Бинарная классификация: обучение линейного классификатора методом градиентного спуска**

Эта лаба продолжает ЛР2. Там веса прямой находили по готовому графику, здесь алгоритм
должен **сам найти** веса по обучающей выборке.

---

## 1. Обучение с учителем

**Обучающая выборка** Xˡ — это ℓ объектов с известными ответами:

Xˡ = {(x₁, y₁), (x₂, y₂), …, (xℓ, yℓ)}

- xᵢ = (1, x₁ᵢ, x₂ᵢ) — признаки i-го объекта с фиктивной единицей;
- yᵢ ∈ {−1, +1} — его класс.

В варианте 7 ℓ = 100: 50 объектов класса +1 и 50 объектов класса −1.

**Обучение** — подбор параметров модели (весов ω) так, чтобы модель как можно реже
ошибалась на обучающей выборке. Правильные ответы известны, отсюда название
«обучение с учителем».

---

## 2. Модель: линейный классификатор

**a(x) = sign⟨ω, x⟩ = sign(ω₀ + ω₁x₁ + ω₂x₂)**

где sign(v) = −1 при v < 0 и +1 при v > 0.

- ω = (ω₀, ω₁, ω₂)ᵀ — вектор весов, задаёт положение разделяющей прямой
  ω₀ + ω₁x₁ + ω₂x₂ = 0;
- x = (1, x₁, x₂)ᵀ — признаки объекта плюс единица, чтобы ω₀ вошёл в скалярное произведение.

Подробно о геометрии прямой и весах см. теорию к ЛР2.

---

## 3. Отступ

**Mᵢ = yᵢ·⟨ω, xᵢ⟩**

- Mᵢ > 0 — объект классифицирован **верно**;
- Mᵢ < 0 — **ошибка**;
- |Mᵢ| пропорционален расстоянию до прямой, т.е. «уверенности» классификатора.

Через отступ удобно записывать всё дальнейшее: функции потерь зависят только от M.

---

## 4. Эмпирический риск

### Что хотим минимизировать

Естественная цель обучения — **число ошибок** на обучающей выборке:

**Q(ω, Xˡ) = Σᵢ [a(xᵢ) ≠ yᵢ] = Σᵢ [Mᵢ < 0]**

Это **эмпирический риск**. [•] — **нотация Айверсона**: [истина] = 1, [ложь] = 0.
Поэтому сумма просто считает объекты с отрицательным отступом.

### Почему напрямую не получается

Функция [M < 0] — **ступенька**:

- при M < 0 она равна 1, при M ≥ 0 равна 0;
- её производная равна 0 везде, кроме точки M = 0, где её нет.

Градиентный спуск движется по производной. Если она нулевая, алгоритм не знает, куда
сдвигать веса: небольшое изменение ω либо не меняет число ошибок вообще, либо меняет его
скачком. Кроме того, точная минимизация числа ошибок — комбинаторная задача, в общем
случае очень сложная (NP-трудная).

### Решение: гладкая верхняя оценка

Ступеньку заменяют **гладкой функцией потерь** L(M), которая лежит **не ниже** неё:

L(M) ≥ [M < 0] для всех M

Тогда

**Q(ω) = Σᵢ [Mᵢ < 0] ≤ Σᵢ L(Mᵢ) = Q̃(ω)**

и минимизируется Q̃(ω). Идея в том, что, «придавливая» верхнюю оценку вниз, мы
придавливаем и число ошибок. Если Q̃ стало меньше 1, то ошибок точно нет: каждая ошибка
вносит в Q̃ не меньше 1.

Часто вместо суммы берут среднее (1/ℓ)·Σ L(Mᵢ). Точка минимума от этого не меняется,
но величина градиента не зависит от размера выборки, и шаг проще подбирать.
В программе используется среднее.

## 5. Функции потерь из таблицы вариантов

Все они **убывают** по M (больше отступ — меньше штраф), **гладкие** и в точке M = 0
равны 1, т.е. касаются ступеньки сверху.

| Название | L(M) | L′(M) | Варианты |
|---|---|---|---|
| Логарифмическая | log₂(1 + e^(−M)) | −1 / ((1 + e^M)·ln 2) | 1, 5, 9 |
| Квадратичная | (1 − M)² | −2(1 − M) | 2, 6, 10 |
| Сигмоидная | 2·(1 + e^M)⁻¹ | −2e^M / (1 + e^M)² | 3, 7 |
| Экспоненциальная | e^(−M) | −e^(−M) | 4, 8 |

### Сравнение

- **Экспоненциальная** (используется в AdaBoost): очень сильно штрафует ошибки,
  при M → −∞ растёт как e^|M|. Поэтому **чувствительна к выбросам**: одна «плохая» точка
  может перетянуть прямую на себя.
- **Логарифмическая** (логистическая регрессия): при больших ошибках растёт примерно
  линейно, мягче экспоненты. Выпуклая, у неё хорошая вероятностная интерпретация.
- **Квадратичная**: штрафует **и** за M > 1, т.е. за «слишком уверенные» верные
  ответы. Это по сути метод наименьших квадратов для ответов ±1. Выпуклая, минимум
  всегда конечен.
- **Сигмоидная** (наш вариант): **ограничена** (0 < S < 2), поэтому выбросы дают
  ограниченный штраф. Зато она **невыпуклая**, подробнее в разделе 7.

## 6. Градиентный спуск

### Идея

**Градиент** ∇Q̃(ω) — вектор частных производных; он указывает направление наискорейшего
**роста** функции. Значит, шаг в обратную сторону уменьшает функцию:

**ω ← ω − η·∇Q̃(ω)**

где η > 0 — **шаг** (темп обучения, learning rate). Повторяем, пока функция не перестанет
заметно уменьшаться.

Аналогия: спуск с горы в тумане. Видно только, в какую сторону склон идёт вниз под ногами,
и мы делаем шаг туда.

### Вывод градиента для любой функции потерь

Q̃(ω) = (1/ℓ)·Σᵢ L(Mᵢ), где Mᵢ = yᵢ·(ω₀·1 + ω₁x₁ᵢ + ω₂x₂ᵢ).

Производная отступа по весу: ∂Mᵢ/∂ωⱼ = yᵢ·xⱼᵢ (для ω₀ это yᵢ·1).

По правилу производной сложной функции:

**∂Q̃/∂ωⱼ = (1/ℓ)·Σᵢ L′(Mᵢ)·yᵢ·xⱼᵢ**

В векторном виде: ∇Q̃ = (1/ℓ)·Σᵢ L′(Mᵢ)·yᵢ·xᵢ.

**Как это понимать.** L′(M) < 0, поэтому шаг ω ← ω − η·∇Q̃ добавляет к ω векторы yᵢ·xᵢ
с весами |L′(Mᵢ)|. Вес ω сдвигается так, чтобы отступы объектов выросли. Сильнее всего
тянут объекты, у которых |L′(Mᵢ)| велик, то есть ошибочные и пограничные.

### Алгоритм

1. Задать начальные веса: ω = (0, 0, 1).
2. Повторять N раз:
   1. посчитать отступы всех объектов: Mᵢ = yᵢ·⟨ω, xᵢ⟩;
   2. посчитать градиент: ∇Q̃ = (1/ℓ)·Σ L′(Mᵢ)·yᵢ·xᵢ;
   3. обновить веса: ω ← ω − η·∇Q̃.
3. Вывести ω, число ошибок, построить график.

### Выбор шага

- Слишком **маленький** η — сходимость очень медленная.
- Слишком **большой** η — алгоритм «перепрыгивает» минимум, функционал скачет или
  расходится.
- Практический способ: попробовать несколько значений и следить, чтобы Q̃ убывал.

### Почему шаг для ω₀ больше

В задании советуют брать шаг для ω₀ больше, чем для ω₁, ω₂. Причины:

1. В градиенте по ω₁ и ω₂ стоят значения признаков (x₁ ≈ 2–4.4), а по ω₀ — единица.
   Компоненты градиента по ω₁, ω₂ получаются крупнее, и при одинаковом шаге они
   менялись бы быстрее ω₀.
2. ω₀ отвечает за **сдвиг** прямой, ω₁ и ω₂ — за её **наклон**. Признаки не центрированы
   (их средние далеко от нуля), поэтому изменение наклона сильно двигает прямую
   в области данных. Задача получается «плохо обусловленной»: в разных направлениях
   функционал меняется с очень разной скоростью. Разные шаги частично это компенсируют.

Другое стандартное решение — **нормализовать признаки** (вычесть среднее, поделить на
стандартное отклонение). Тогда хватает одного шага на все веса.

### Когда останавливаться

- после фиксированного числа итераций (так сделано в программе, 3000);
- когда изменение Q̃ или ω между итерациями стало меньше заданного порога;
- когда норма градиента стала близка к нулю.

### Полный и стохастический градиентный спуск

- **Полный (batch)** — градиент считается по всей выборке на каждом шаге.
  Так сделано в лабе: 100 объектов — это мало.
- **Стохастический (SGD)** — на каждом шаге берётся один случайный объект (или небольшая
  пачка), градиент считается только по нему. Для больших выборок это гораздо быстрее,
  но спуск получается «шумным».

## 7. Сигмоидная функция потерь подробно (вариант 7)

**S(M) = 2 / (1 + e^M)**

### Значения

| M | −∞ | −2 | 0 | 2 | +∞ |
|---|---|---|---|---|---|
| S(M) | 2 | 1.76 | 1 | 0.24 | 0 |

- S(0) = 1 — касается ступеньки [M < 0] в нуле;
- при M < 0: e^M < 1 ⇒ S > 1 ⇒ S ≥ [M < 0] — верхняя оценка ✔;
- при M ≥ 0: S > 0 = [M < 0] ✔.

Название: S(M) = 1 − th(M/2), т.е. это перевёрнутая и растянутая сигмоида
(S-образная кривая).

### Производная

S(M) = 2·(1 + e^M)⁻¹

S′(M) = 2·(−1)·(1 + e^M)⁻²·e^M = **−2e^M / (1 + e^M)²**

Удобная форма: S′(M) = −S(M)·(2 − S(M)) / 2.

Производная всегда отрицательна (функция убывает). По модулю она **максимальна при M = 0**
(S′(0) = −0.5) и **стремится к нулю** при M → ±∞.

### Что из этого следует

1. **Устойчивость к выбросам.** У объекта, который глубоко на чужой стороне (M ≪ 0),
   S′ ≈ 0, и он почти не влияет на градиент. Прямую определяют в основном
   **пограничные** объекты, у которых M близко к 0.
2. **Невыпуклость.** Функционал может иметь несколько локальных минимумов и «плато».
   Если начать с весов, при которых почти все объекты сильно ошибаются, градиент будет
   почти нулевым, и спуск может застрять. Поэтому важно разумное начальное приближение.
   Начальная прямая (0, 0, 1) — это x₂ = 0; её отступы небольшие, и спуск стартует нормально.
3. **Рост весов на разделимой выборке.** Если все объекты уже классифицированы верно,
   функционал можно уменьшать дальше, просто увеличивая ω (все M растут, S → 0).
   Минимум не достигается при конечных весах, веса растут бесконечно, хотя прямая почти
   не меняется. Поэтому число итераций ограничивают. То же верно для логарифмической и
   экспоненциальной потерь, но не для квадратичной.

## 8. Результаты варианта 7 и как их читать

| Итерация | Q̃ | ω | Прямая x₂ = … |
|---|---|---|---|
| 0 | 0.773 | (0, 0, 1) | x₂ = 0 |
| 1000 | 0.076 | (1.76, −1.93, 5.33) | 0.362·x₁ − 0.330 |
| 3000 | 0.029 | (2.43, −2.66, 7.26) | 0.366·x₁ − 0.335 |

- На старте прямая x₂ = 0 ниже всех точек: все объекты отнесены к классу +1,
  т.е. 50 ошибок из 100.
- После обучения ошибок **0**: выборка линейно разделима. У класса +1 x₂ ∈ [1.0; 1.8],
  у класса −1 x₂ ∈ [0.1; 0.6], поэтому главный признак — x₂. Поэтому |ω₂| самый большой.
- С 1000-й по 3000-ю итерацию **прямая почти не сдвинулась**, но веса выросли
  примерно в 1.4 раза. Это и есть эффект из п. 7.3: функционал убывает за счёт роста
  «уверенности», а не за счёт перемещения прямой.
- Функционал убывал на каждой итерации: шаг выбран не слишком большим.

Уравнение прямой из весов: ω₀ + ω₁x₁ + ω₂x₂ = 0 ⇒ **x₂ = −(ω₀ + ω₁x₁) / ω₂**.
Эта же формула используется в программе, чтобы нарисовать линию.

## 9. Шпаргалка

- Модель: a(x) = sign⟨ω, x⟩, x = (1, x₁, x₂).
- Отступ: Mᵢ = yᵢ⟨ω, xᵢ⟩; M < 0 — ошибка.
- Эмпирический риск: Q = Σ[Mᵢ < 0] — число ошибок; его градиент бесполезен (ступенька).
- Верхняя оценка: Q ≤ Q̃ = Σ L(Mᵢ), где L — гладкая убывающая функция, L(M) ≥ [M < 0].
- Градиент: ∂Q̃/∂ωⱼ = (1/ℓ)·Σ L′(Mᵢ)·yᵢ·xⱼᵢ.
- Шаг: ω ← ω − η·∇Q̃.
- Сигмоидная: S = 2/(1 + e^M), S′ = −2e^M/(1 + e^M)².

## 10. Возможные вопросы на защите

1. **Что такое эмпирический риск?**
   Число (или доля) ошибок модели на обучающей выборке: Σ[Mᵢ < 0].
2. **Что такое нотация Айверсона?**
   [условие] = 1, если условие истинно, иначе 0.
3. **Почему нельзя минимизировать эмпирический риск градиентным спуском напрямую?**
   Функция ступенчатая: производная равна нулю почти везде, градиент не показывает направление.
4. **Зачем нужна функция потерь и какие к ней требования?**
   Гладкая верхняя оценка ступеньки: L(M) ≥ [M < 0], дифференцируемая, убывающая по M.
5. **Выведите градиент.**
   ∂Q̃/∂ωⱼ = (1/ℓ)·Σ L′(Mᵢ)·yᵢ·xⱼᵢ, т.к. ∂Mᵢ/∂ωⱼ = yᵢxⱼᵢ.
6. **Почему минус в формуле шага?**
   Градиент указывает направление роста функции, а нам нужно её уменьшать.
7. **Что будет при слишком большом / маленьком шаге?**
   Большой — расходимость или колебания; маленький — очень медленная сходимость.
8. **Зачем для ω₀ шаг больше?**
   Компонента градиента по ω₀ не домножается на признаки (x₀ = 1), и без большего шага
   сдвиг прямой подстраивается медленнее наклона. Альтернатива — нормализация признаков.
9. **Чем хороша и чем плоха сигмоидная функция потерь?**
   Плюс: ограничена, поэтому устойчива к выбросам. Минус: невыпуклая, возможны
   локальные минимумы и затухание градиента.
10. **Почему веса продолжают расти, хотя ошибок уже нет?**
    На разделимой выборке функционал уменьшается при растягивании ω: отступы растут,
    потери стремятся к 0. Минимум не достигается при конечных весах.
11. **Как по весам построить разделяющую линию?**
    x₂ = −(ω₀ + ω₁x₁)/ω₂.
