# Теория к лабораторной работе № 2

**Разделяющая линия и отступ (margin) в линейной бинарной классификации**

---

## 1. Постановка задачи классификации

Есть объекты, каждый описан набором **признаков**. В лабе признаков два, поэтому объект —
это точка на плоскости:

x = (x₁, x₂)

У каждого объекта есть **метка класса** y. Классов два, метки такие:

- y = +1 (в лабе — зелёные точки);
- y = −1 (в лабе — синие точки).

Задача **бинарной классификации** — построить правило (алгоритм) a(x), которое по признакам
объекта предсказывает его класс: a(x) ∈ {−1, +1}.

---

## 2. Линейный классификатор

Самое простое правило — разрезать плоскость прямой линией на две полуплоскости: по одну
сторону прямой объекты относим к классу +1, по другую — к классу −1.

Прямая на плоскости задаётся уравнением

**ω₁·x₁ + ω₂·x₂ + ω₀ = 0**

- ω₁, ω₂ — **веса** признаков;
- ω₀ — **смещение** (bias, свободный член).

Эта прямая называется **разделяющей линией** (в многомерном случае — разделяющей
гиперплоскостью).

### Решающее правило

Подставим в левую часть уравнения координаты точки:

f(x) = ω₁·x₁ + ω₂·x₂ + ω₀

- f(x) = 0 — точка лежит **на** прямой;
- f(x) > 0 — точка по одну сторону прямой;
- f(x) < 0 — точка по другую сторону.

Классификатор:

**a(x) = sign(f(x)) = sign(ω₁·x₁ + ω₂·x₂ + ω₀)**

### Запись через скалярное произведение

Чтобы не таскать ω₀ отдельно, к каждому объекту добавляют **фиктивный признак x₀ = 1**:

x = (1, x₁, x₂), ω = (ω₀, ω₁, ω₂)

Тогда

f(x) = ⟨ω, x⟩ = ω₀·1 + ω₁·x₁ + ω₂·x₂

где ⟨ω, x⟩ — **скалярное произведение** векторов (сумма попарных произведений координат).
Именно так записана формула в задании.

---

## 3. Геометрический смысл весов

### Вектор (ω₁, ω₂) — нормаль к прямой

Вектор n = (ω₁, ω₂) **перпендикулярен** разделяющей прямой и указывает в сторону, где
f(x) > 0, то есть в сторону класса +1 (если классификатор угадывает).

Отсюда:

- **ω₂ = 0** — нормаль горизонтальна, значит прямая **вертикальная**: x₁ = −ω₀/ω₁;
- **ω₁ = 0** — нормаль вертикальна, значит прямая **горизонтальная**: x₂ = −ω₀/ω₂;
- ω₀ сдвигает прямую параллельно самой себе; при ω₀ = 0 прямая проходит через начало
  координат.

### Расстояние от точки до прямой

**ρ(x) = |ω₁·x₁ + ω₂·x₂ + ω₀| / √(ω₁² + ω₂²)**

То есть |f(x)| **пропорционально** расстоянию до прямой. Если вектор (ω₁, ω₂) нормирован
(его длина равна 1), то |f(x)| — это ровно расстояние.

### Веса определены с точностью до множителя

Уравнения

x₂ − 4 = 0, 2x₂ − 8 = 0, −x₂ + 4 = 0

задают **одну и ту же прямую**. Умножение всех весов на число k ≠ 0 прямую не меняет, но:

- при k > 0 сохраняется, какая сторона «плюсовая»;
- при k < 0 стороны **меняются местами**: классификатор начинает отвечать наоборот.

Поэтому по одному рисунку прямой веса нельзя определить однозначно: нужно
дополнительное условие, которое фиксирует знак (и при желании масштаб). В лабе
это условие на знаки отступов (см. раздел 5).

---

## 4. Как найти коэффициенты прямой по графику

### Вертикальная прямая x₁ = c

ω₂ = 0, уравнение ω₁·x₁ + ω₀ = 0 ⇒ x₁ = −ω₀/ω₁ = c.
Например, ω = (ω₀, ω₁, ω₂) = (−c, 1, 0) или (c, −1, 0).

### Горизонтальная прямая x₂ = c

ω₁ = 0, аналогично: ω = (−c, 0, 1) или (c, 0, −1).

### Наклонная прямая

Берём на графике две точки прямой, лучше в узлах сетки: (a₁, a₂) и (b₁, b₂).

Уравнение прямой через две точки:

(x₁ − a₁)·(b₂ − a₂) − (x₂ − a₂)·(b₁ − a₁) = 0

Раскрываем скобки и получаем:

- ω₁ = b₂ − a₂
- ω₂ = −(b₁ − a₁)
- ω₀ = −(ω₁·a₁ + ω₂·a₂)

**Пример.** Прямая проходит через (0; 1) и (4; 5):
ω₁ = 5 − 1 = 4, ω₂ = −(4 − 0) = −4, ω₀ = −(4·0 − 4·1) = 4.
Получаем 4x₁ − 4x₂ + 4 = 0, после деления на 4: x₁ − x₂ + 1 = 0, т.е. x₂ = x₁ + 1. ✔

Другой способ — через угловой коэффициент x₂ = k·x₁ + b:
k·x₁ − x₂ + b = 0 ⇒ ω = (b, k, −1) (или с обратным знаком).

**Проверка:** подставить обе точки в уравнение, должно получиться 0.

## 5. Отступ (margin)

### Определение

Отступ объекта xᵢ с меткой yᵢ:

**Mᵢ = yᵢ · ⟨ω, xᵢ⟩ = yᵢ · (ω₀ + ω₁·x₁ + ω₂·x₂)**

### Смысл знака

Классификатор отвечает sign⟨ω, x⟩, правильный ответ — y. Получаем:

| Ситуация | sign⟨ω, x⟩ и y | M |
|---|---|---|
| Классификатор **прав** | совпадают | **M > 0** |
| Классификатор **ошибся** | разные | **M < 0** |
| Точка на разделяющей прямой | ⟨ω, x⟩ = 0 | M = 0 |

Главное: **знак отступа показывает, верно ли классифицирован объект.**
Умножение на y «выравнивает» оба класса: для любого класса хорошо, когда M > 0.

### Смысл модуля

|M| пропорционален расстоянию от точки до прямой, поэтому модуль показывает
**уверенность** классификатора:

- большой положительный M — объект уверенно классифицирован верно, далеко от границы;
- M около 0 — объект у границы, классификатор «сомневается»;
- большой отрицательный M — грубая ошибка: объект глубоко на чужой стороне,
  это может быть выброс или ошибка в разметке.

### Отступ и масштаб весов

При умножении ω на k > 0 все отступы тоже умножаются на k: знаки сохраняются, меняются
только величины. Поэтому сравнивать отступы разных точек можно при одних и тех же ω,
а сравнивать абсолютные значения между разными ω без нормировки нельзя.
Нормированный отступ Mᵢ / √(ω₁² + ω₂²) — это расстояние до прямой со знаком.

### Условие из задания

В задании нужно подобрать ω так, чтобы у точек, **дальних** от линии, отступ был
**положительным**, а у **ближних** — **отрицательным**.

Прямая одна и та же, выбрать можно только **знак** весов (см. раздел 3). Схема:

1. Записать прямую с произвольным знаком, например ω = (4, 0, −1).
2. Посчитать отступы.
3. Если знаки получились наоборот, умножить все веса на −1: все отступы сменят знак.

## 6. Разбор варианта 2

По графику: прямая x₂ = 4; зелёные (+1) точки (2; 3) и (5; 7); синие (−1) — (6; 5) и (7; 2).

**Шаг 1.** Прямая горизонтальная ⇒ ω₁ = 0. Пробуем ω = (4, 0, −1), т.е. −x₂ + 4 = 0.

**Шаг 2.** Считаем отступы:

| Точка | y | ⟨ω, x⟩ = 4 − x₂ | M | Расстояние | Дальняя/ближняя |
|---|---|---|---|---|---|
| (2; 3) зел. | +1 | 1 | 1 | 1 | ближняя |
| (5; 7) зел. | +1 | −3 | −3 | 3 | дальняя |
| (6; 5) син. | −1 | −1 | 1 | 1 | ближняя |
| (7; 2) син. | −1 | 2 | −2 | 2 | дальняя |

Знаки противоположны требуемым: у дальних точек M < 0.

**Шаг 3.** Умножаем на −1: ω = (−4, 0, 1), прямая x₂ − 4 = 0.
Отступы: −1, 3, −1, 2. У дальних точек M > 0, у ближних M < 0. ✔

**Интерпретация.** Здесь ω₁ = 0 и |ω₂| = 1, поэтому |M| равен расстоянию до прямой
в клетках. Классификатор с ω = (−4, 0, 1) относит верхнюю полуплоскость (x₂ > 4) к классу +1,
а нижнюю — к классу −1. Верно классифицированы (5; 7) и (7; 2), ошибки на (2; 3) и (6; 5).
Точность 2/4 = 50 %: одной горизонтальной прямой эти точки не разделить.

## 7. Зачем нужен отступ в машинном обучении

Отступ — основа обучения линейных классификаторов.

### Число ошибок через отступ

Долю ошибок на выборке из ℓ объектов можно записать как

Q(ω) = (1/ℓ) · Σ [Mᵢ < 0]

где [·] равно 1, если условие выполнено, и 0 иначе. Эта функция ступенчатая,
её нельзя минимизировать градиентными методами, поэтому её заменяют гладкой
**функцией потерь от отступа** L(M), которая убывает с ростом M:

| Метод | Функция потерь L(M) |
|---|---|
| Персептрон | max(0, −M) |
| SVM (hinge loss) | max(0, 1 − M) |
| Логистическая регрессия | log₂(1 + e^(−M)) |
| Экспоненциальная (AdaBoost) | e^(−M) |

Все они «штрафуют» отрицательные и маленькие положительные отступы, поэтому
обучение сводится к тому, чтобы **сделать отступы всех объектов как можно больше**.

### Максимальный зазор (SVM)

Метод опорных векторов выбирает прямую, у которой **минимальный отступ** (расстояние
до ближайшей точки) максимален. Прямую проводят «посередине» между классами,
как можно дальше от обоих. Ближайшие к ней точки называются **опорными векторами**.

### Анализ выборки по отступам

Если отсортировать объекты по M, видно следующее:

- M ≪ 0 — возможные **выбросы** или ошибки разметки;
- M ≈ 0 — **пограничные** объекты;
- M ≫ 0 — **эталонные**, надёжно классифицируемые объекты.

## 8. Краткая шпаргалка

- Разделяющая прямая: ω₁x₁ + ω₂x₂ + ω₀ = 0.
- С фиктивным признаком: x = (1, x₁, x₂), f(x) = ⟨ω, x⟩.
- Классификатор: a(x) = sign⟨ω, x⟩.
- (ω₁, ω₂) — нормаль к прямой, указывает на сторону класса +1.
- Вертикальная прямая x₁ = c ⇒ ω₂ = 0; горизонтальная x₂ = c ⇒ ω₁ = 0.
- Веса определены с точностью до множителя; знак множителя меняет стороны классов.
- Отступ: M = y·⟨ω, x⟩. M > 0 — верно, M < 0 — ошибка, |M| ~ расстояние до прямой.
- Расстояние: |⟨ω, x⟩| / √(ω₁² + ω₂²).

## 9. Возможные вопросы на защите

1. **Что такое отступ и что означает его знак?**
   M = y·⟨ω, x⟩; M > 0 — объект классифицирован верно, M < 0 — ошибка.
2. **Почему веса прямой определяются неоднозначно?**
   Умножение уравнения на k ≠ 0 даёт ту же прямую; знак k определяет, какой класс с какой
   стороны.
3. **Зачем фиктивный признак x₀ = 1?**
   Чтобы смещение ω₀ вошло в скалярное произведение и формулы записывались компактно.
4. **Что означает ω₁ = 0 в вашем варианте?**
   Прямая горизонтальная, классификация зависит только от признака x₂.
5. **Как связан отступ с расстоянием до прямой?**
   Расстояние со знаком равно M / √(ω₁² + ω₂²); при единичной нормали M и есть это расстояние.
6. **Где отступ используется при обучении?**
   Функции потерь (персептрон, SVM, логистическая регрессия) — это функции от отступа;
   обучение увеличивает отступы объектов.
